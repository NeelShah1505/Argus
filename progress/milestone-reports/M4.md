## 1. Deliverables Completed

1. **Typed Calculation Engine (`packages/calc/registry.py`)**
   - Registered standard corporate financial formulas:
     - `revenue_growth`: $(R_t - R_{t-1}) / R_{t-1}$
     - `gross_margin`: $\text{Gross Profit} / \text{Revenue}$
     - `operating_margin`: $\text{Operating Income} / \text{Revenue}$
     - `current_ratio`: $\text{Current Assets} / \text{Current Liabilities}$
   - Strict execution guards:
     - All inputs must be Tier $V$ or Tier $E$. Input with Tier $R$ or $F$ raises `CalculationError` and blocks computation.
     - Currency compatibility check: mismatched currencies (e.g., USD vs. EUR) are rejected.
     - Zero denominator protection.
     - Tier inheritance: derived metric automatically inherits the lowest tier among its inputs.

2. **Lineage DAG & Invalidation (`packages/calc/lineage.py`)**
   - Tracks full dependency graph: `DerivedMetric -> Formula -> Input Fact IDs -> Evidence Bboxes`.
   - `invalidate_fact`: When a primary fact is corrected or modified, all downstream metrics that depend on it are instantly purged/invalidated.

3. **REST Calculation API (`apps/api/routers/calc.py`)**
   - `POST /api/v1/calculations/run`: Executes registry calculations given input fact IDs.
   - `GET /api/v1/lineage/{metric_id}`: Returns the complete mini-DAG trace for the UI Lineage Drawer.
   - `GET /api/v1/facts`: Queries verified facts filtered by entity, metric, or period.
